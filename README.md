# Litera

## Description
Litera — кроссплатформенный книжный онлайн-магазин, предназначенный для подбора, покупки и отслеживания доставки печатных и электронных изданий. Платформа включает полнофункциональный веб-сервис и нативное мобильное приложение с каталогом, тематическими фильтрами, поиском по авторам/издательствам и оформлением предзаказов. Для персонала реализована панель управления заказами, учёта складских остатков и администрирования карточек книг. Проект разрабатывается в рамках курса «Проектирование человеко-машинных интерфейсов».

## Installation
Инструкция по локальному развертыванию инфраструктуры проекта:
1. Клонирование основного репозитория вместе со всеми связанными подмодулями:
   ```bash
   git clone --recurse-submodules https://github.com/fpmi-hci-2026/Litera.git
   cd Litera

2. Инициализация и синхронизация подмодулей (если репозиторий уже был клонирован без флага --recurse-submodules):
   git submodule update --init --recursive
   
3. Локальная установка зависимостей и запуск сервисов осуществляются отдельно для каждого модуля в соответствии с инструкциями в их внутренних директориях.

Sub modules

⚬ Litera-Web — фронтенд-приложение онлайн-магазина (веб-каталог, корзина, оформление заказов).

⚬ Litera-Server — серверная часть, бизнес-логика обработки заказов и REST API.

⚬ Litera-Mobile — мобильный клиент книжного магазина для операционных систем Android/iOS.

Usage

⚬ Веб-версия витрины магазина доступна локально по адресу: http://localhost:3000.

⚬ Серверный API и Swagger-документация доступны по адресу: http://localhost:8000/api/docs.

⚬ Документация и отчёты по проектированию интерфейсов опубликованы на GitHub Pages: https://fpmi-hci-2026.github.io/Litera/.
